# Inventory + Sales Management System

A Python-based application designed to manage product inventory and sales records efficiently using Pandas and CSV file handling.

### Features
- Add, update and delete products.
- Sell products and manage stock.
- Automatically generate product IDs.
- Track sales and calculate revenue.
- Generate sales reports.

### Technologies Used
- Python 3
- Pandas
- CSV File Handling

### How to Run
```bash
pip install pandas
python main.py
```
